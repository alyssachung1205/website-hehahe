# 個人自我介紹網站

以 HTML、CSS 和少量 JavaScript 製作的響應式個人介紹頁，內容依自我介紹資料整理，並使用 `profile.jpg` 個人照片，無需安裝套件。

## 在電腦上預覽

直接用瀏覽器開啟 `index.html` 即可。若使用 VS Code，也可以安裝 Live Server，對 `index.html` 按右鍵並選擇 **Open with Live Server**。

在 `index.html` 搜尋並替換以下範例文字：

- 頁面文字、興趣和學習紀錄可直接在 `index.html` 編輯。
- 若要更換個人照片，請以自己的圖片取代 `profile.jpg`。

頁面插畫和自然系配色都由 CSS／SVG 製作，不需要額外圖片。

## 發布到 GitHub Pages

1. 在 GitHub 建立一個新的 repository。
2. 將本資料夾中的 `index.html`、`style.css`、`script.js`、`README.md` 和 `profile.jpg` 一起放在 repository 根目錄。
3. 到 repository 的 **Settings → Pages**，在 **Build and deployment** 選擇 **Deploy from a branch**。
4. 選擇 `main` 分支和 `/(root)` 資料夾後儲存，等待 GitHub Pages 顯示網站網址。

此網站不依賴建置工具，適合使用 GitHub Pages 發布。
